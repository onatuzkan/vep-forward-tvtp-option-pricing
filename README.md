# Energy Markets Options Valuation

PDE-based option valuation model for Turkish electricity markets, calibrated to VEP monthly forward quotes with a regime-switching residual-demand driver.

## Repository layout

- `config/` — YAML configuration files (PDE grid, forward-centered mode, M2 clean run).
- `inputs/` — Input data: historical residual-demand series, VEP market quotes, legacy reference forwards.
- `pde_option_model/` — Python package: PDE solver, forward calibration, dynamics, contracts, diagnostics.
- `tests/` — Pytest suite (154 tests) covering calibration acceptance, forward curve, legacy moments, CLI, etc.
- `outputs/` — Generated artifacts (calibration results, diagnostics, scenario sweeps). Regenerated by the CLI.
- `docs/` — Team manual and reference documentation.

## Running the tests

```
python -m pytest -q
```
