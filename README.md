# Energy Markets Options Valuation

PDE-based European option pricer for the Turkish day-ahead market (EPİAŞ
PTF, TRY/MWh).  The price *level* is anchored to the EPİAŞ VEP monthly
baseload forward strip; the *residual* around that curve follows a
two-regime TVTP (time-varying transition probability) Markov-switching OU
process whose parameters are inherited from the M9 fit of the historical
hourly PTF series.  Every option value produced here is labelled
**"VEP-forward-curve anchored option prices"** — only the first moment is
market-identified; volatility and regime-transition risk premia are not.

## Running

```
# 1. Structural / numerical self-checks (no calibration, ~1 s)
python run_pde.py validate

# 2. Rebuild the accepted forward-curve calibration under the frozen yaml
python run_pde.py calibrate-market --model forward_centered \
    --outdir outputs/market_calibration_final

# 3. Price a 72 h European call at K = 3000 TRY/MWh (PDE + Monte Carlo cross-check)
python run_pde.py price --model forward_centered \
    --curve outputs/market_calibration_final \
    --option-type call --strike 3000 --maturity-hours 72

# 4. RD-scenario sweep (±2σ standardized RD offset, 9 rows)
python scenario_sweep.py

# 5. Full test suite (169 passed)
python -m pytest -q
```

### Optional: sensitivity to the regime-probability initial condition

The default `pi_filtered` on the frozen yaml is the M2-shipped filter
`[0.9320, 0.0680]`; a valuation-time M9 filter is not available.  Under
`--pi-override stationary` the pricer swaps in the M9 stationary
occupancy `[0.3254, 0.6746]` — impact <2 % on 72 h+ maturities, up to
~30 % on <24 h maturities.  See `model_limitations.md` item (e).

```
python run_pde.py price --model forward_centered \
    --curve outputs/market_calibration_final \
    --strike 3000 --maturity-hours 72 --pi-override stationary
```

## Calibration history

* The forward curve is calibrated exactly to the six-month VEP quote
  strip (Feb-Jul 2026); the January 2026 window is anchored by the
  production `spot_to_next_linear` rule (accepted after the anchor-mode
  review under `outputs/market_calibration_final/archive/near_term_anchor_review/`).
* TVTP volatilities and gamma slopes are the M9 fit values (regime-label
  swapped to the yaml convention).  The two `alpha` intercepts are
  **derived**, not MLE-estimated: they are back-solved from the reported
  M9 mean-duration diagnostics via `scripts/tvtp_derivation/derive_tvtp_parameters.py`.
  Full derivation and cross-check are in
  [`docs/tvtp_derivation_methodology.md`](docs/tvtp_derivation_methodology.md).
* Every acceptance / provenance caveat is auto-included in the
  regenerated `outputs/market_calibration_final/model_limitations.md`
  (items (a)-(e)).

## What is *not* identified without option premia

Volatility risk premium, regime-transition premia η₀₁ / η₁₀, and any
regime-specific market price of risk λᵢ are not identifiable from
forward quotes alone.  See the "4_not_identified_without_option_prices"
block in `outputs/market_calibration_final/parameter_identification.json`
and the pricing-label warning in every emitted YAML/JSON.
